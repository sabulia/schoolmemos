# 校园版 memos（Campus Memos）需求规格说明书（优化版）

> 本文档是在原始修改要求基础上，按照「可落地、可验收、贴合双创评审」原则优化后的版本。
> 优化原则：合并同类项、明确验收标准、标注依赖与边界、区分本期实现（v1）与后续迭代（v2）。

## 0. 与原需求的对照说明（做了哪些优化）

| 原要求 | 优化后 | 优化理由 |
| --- | --- | --- |
| 「抓取登录可见和公开的 memo 中的关键词并按相关性分类」 | 明确为：服务端在 memo 创建/更新时自动提取关键词（中文 n-gram + 显式 #标签 融合），按「关键词—主题词库相关性得分」归入 10 个主题分类；管理员可一键重建索引 | 明确触发时机、算法路线与主题集合，可验收 |
| 「好友、群、圈、话题区、推荐、主题分类、我的」七个分区 | 保留七分区，置于顶部导航栏（仿抖音顶栏）；复用原项目的 Space 承载「群」，memo + 好友关系承载「好友」，memo 可见性承载「圈」，#标签 承载「话题区」 | 最大化复用原项目能力，减少重复造轮子 |
| 「匿名/实名发布」 | 定义为 memo 级 `anonymous` 标志：匿名内容在任何浏览者视角均隐藏作者信息（昵称显示为「匿名同学」、无头像、不可点击主页）；作者在「我的」中可见并管理自己的匿名内容 | 明确匿名的作用范围与例外 |
| 「网页版和 app 版，支持下载到电脑桌面和手机桌面」 | 实现为 PWA：一次构建同时是网页版与可安装应用（手机桌面图标 / 电脑桌面窗口）；「我的-设置-下载到本地」提供手机端/电脑端安装入口；注册成功后仅提示一次；搜索框搜「下载」时下载入口置顶 | 用 PWA 替代双端原生开发，校园团队可维护；明确「只问一次」「搜索置顶」的交互细节 |
| 「日程表导入时间表并到时提示」 | 每条 memo 可附加日程时间与提前提醒分钟数；支持导出标准 ICS 订阅链接（含 VALARM 提醒），可导入系统日历；应用内日历页展示 | ICS 是跨平台标准，避免自研推送体系（v2 再做站内推送） |
| 「询问是否接受推荐」 | 首次进入「推荐」页弹出询问；同意后基于点赞（reaction）、收藏、浏览记录做关键词相关性推荐；拒绝则不采集行为数据用于推荐 | 符合个人信息保护的「明示同意」要求 |
| 「评论/群/圈/话题区可匿名」 | 同「匿名发布」，作用域覆盖 memo 与评论 | 合并同类项 |
| 「登录只需用户名和密码」 | 与原项目一致，保持不变 | 原项目已满足 |
| 「简化注册：用户名+密码+手机号+短信验证」「找回密码：用户名+手机号+短信验证」 | 新增校园注册/找回密码通道；短信通道抽象为 Provider 接口，默认内置「开发模式 Provider」（验证码回显/写日志），预留 Webhook Provider 对接阿里云/腾讯云短信 | 短信服务依赖运营商资质，接口抽象后可在比赛现场用开发模式演示 |
| 「隐私设置：日期表/自己发的 memo/浏览记录/收藏 分别可公开或不公开；每条 memo 独立设置 仅自己/仅好友/登录可见/完全公开」 | 个人主页四类内容各有公开开关；memo 可见性四档，其中「仅好友可见」为校园版新增（原项目三档：PRIVATE/PROTECTED/PUBLIC），底层存储为 PRIVATE + 好友关系校验，防止越权 | 明确技术实现路径，保证安全性 |
| 「界面默认简洁，可在设置中为不同功能区设置界面，支持静态图片和动态画面」 | 「我的-设置-界面个性化」：可为每个功能区分别选择 默认简洁/静态壁纸/动态壁纸（CSS 动画背景，仿手机动态壁纸） | 用 CSS 动效实现动态画面，零第三方依赖 |
| 「一条命令装完」 | 提供 `scripts/install-campus.sh`（Linux/macOS）与 `install-campus.ps1`（Windows）：有 Docker 用 Docker，无 Docker 自动下载单二进制；装完打印访问地址 | 明确两条命令路径与回退策略 |
| 「数据导出」 | 「我的-设置-数据导出」+ 管理员导出：CSV/JSON 两种格式，含按主题/按日期的统计汇总，可直接用于向学校汇报 | 明确格式与汇报场景 |

## 1. 功能需求（v1 本期实现）

### 1.1 关键词提取与主题分类
- F1：memo 创建/更新时自动提取关键词：中文 2-4 元 n-gram 频度统计 + 英文单词 + 显式 `#标签` 融合，取 Top-K（K=8）。
- F2：按「关键词—主题词库」相关性得分归入主题分类，主题集合：失物招领、学习打卡、求助问答、二手交易、社团活动、通知公告、考试升学、生活分享、兴趣圈子、其他。
- F3：「主题分类」页按主题分栏展示词条与 memo（仿番茄免费小说的分类书架交互）。
- F4：管理员可一键重建全站关键词索引（POST /api/campus/reindex）。

### 1.2 七大功能分区（顶部导航）
| 分区 | 参考 | 核心功能 |
| --- | --- | --- |
| 好友 | 微信 | 按用户名搜索添加、申请/通过、好友列表、好友动态、私信式会话（基于仅彼此可见 memo） |
| 群 | 微信 | 基于原项目 Space：建群、邀请、群内动态流 |
| 圈 | QQ 动态/朋友圈/Ins/Twitter | 全校公开+登录可见动态流，卡片式，点赞/评论，支持匿名 |
| 话题区 | 小红书/贴吧 | #话题 聚合页、话题吧列表、按热度/时间排序、话题下发帖 |
| 推荐 | 抖音/B站 | 首次进入询问授权；同意后按点赞/收藏/浏览记录做关键词相关性推送 |
| 主题分类 | 番茄免费小说 | 见 1.1 |
| 我的 | — | 日期表（日历）、我发布的 memo、浏览记录、我的收藏、设置 |

### 1.3 匿名发布
- 发布器提供「匿名发布」开关；匿名内容对浏览者隐藏作者信息；作者本人在「我的」中可见。

### 1.4 注册 / 登录 / 找回密码
- 注册：用户名（唯一）+ 密码 + 手机号 + 短信验证码。
- 登录：用户名 + 密码。
- 找回密码：用户名 + 手机号 + 短信验证码 → 重置密码。
- 短信 Provider：开发模式（回显验证码）/ Webhook（对接第三方短信网关）。

### 1.5 隐私设置
- 个人主页四开关：日期表 / 我的 memo / 浏览记录 / 收藏 是否公开。
- 单条 memo 四档可见性：仅自己可见 / 仅好友可见 / 登录可见 / 完全公开。

### 1.6 推荐授权
- 首次进入「推荐」页弹窗询问；同意后才采集点赞/收藏/浏览用于推荐；可随时在设置中关闭。

### 1.7 日程导入与提醒
- memo 可附「日程时间 + 提前提醒分钟数」；提供 ICS 订阅链接（含 VALARM），一键导入系统日历；应用内日历页展示。

### 1.8 下载到本地（PWA）
- 「我的-设置-下载到本地」：手机端/电脑端两个入口（PWA 安装指引 + 浏览器安装提示）。
- 注册成功后弹出一次「是否安装到桌面」，此后不再询问。
- 在搜索框搜索「下载」时，下载入口卡片置顶。

### 1.9 界面个性化
- 默认简洁风格；可为每个分区单独设置 默认/静态壁纸/动态壁纸（CSS 动效）。

### 1.10 一键部署
- `bash scripts/install-campus.sh`（或 Windows PowerShell 一条命令）：优先 Docker，无 Docker 则下载单二进制；完成打印本机访问地址。

### 1.11 数据导出
- 个人导出：自己的全部 memo（JSON/CSV）。
- 管理员导出：全站数据 + 按主题/按日统计汇总（用于向学校汇报、成果展示）。

## 2. 非功能需求
- N1 安全：匿名不可逆（服务端不落作者昵称到前端）；「仅好友可见」服务端鉴权，不依赖前端隐藏。
- N2 隐私：推荐须明示同意；浏览记录仅本人可见（除非主动公开）。
- N3 兼容：保持原项目 MIT 许可与全部原有功能可用；校园功能全部增量实现，不破坏原 API。
- N4 轻量：不引入新的重型依赖；单二进制 + SQLite 即可运行。

## 3. 边界与不做的事（v1）
- 不做原生 iOS/Android 安装包（用 PWA 覆盖，v2 可套壳 Tauri/Capacitor）。
- 不做真实运营商短信通道（提供接口与开发模式，比赛/试点用 Webhook 对接）。
- 不做站内消息推送（日程提醒走 ICS/系统日历，v2 可加 Web Push）。
